# Burger Landing Page Design System

## Brand Direction

The landing page uses a **Bold Modern Diner** visual style combining contemporary food photography, playful typography, and retro fast-food influences.

The experience should feel:

* Appetizing
* Energetic
* Friendly
* Bold
* Modern
* Slightly playful
* Premium without feeling expensive

The burger itself must remain the strongest visual element on the page.

Avoid overly corporate layouts, excessive gradients, glassmorphism, or generic SaaS-style cards.

---

## Color Palette

### Primary

```css
--color-primary: #e6392f;
--color-primary-hover: #c92f27;
--color-on-primary: #ffffff;
```

Ketchup-inspired red used for:

* Primary CTA
* Promotional badges
* Important highlights
* Active states

### Secondary

```css
--color-secondary: #f4b942;
--color-secondary-hover: #dfa62e;
--color-on-secondary: #1f1a17;
```

Mustard yellow used for:

* Secondary CTA
* Price highlights
* Decorative shapes
* Promotional sections

### Background

```css
--color-background: #fff8ed;
--color-surface: #ffffff;
--color-surface-secondary: #f7ead8;
```

Use warm cream instead of pure white to create a warmer food-oriented experience.

### Text

```css
--color-text-primary: #211915;
--color-text-secondary: #74665e;
--color-text-muted: #9a8b82;
```

### Accent

```css
--color-accent-green: #49794a;
--color-accent-orange: #f07832;
```

Green can be used for:

* Fresh ingredients
* Vegetarian labels
* Natural ingredients

Orange can be used for promotional decorations and spicy menu items.

# Typography

Use typography with strong personality.

## Display Font

Recommended:

**Bebas Neue**

Alternative:

* Anton
* Oswald
* Archivo Black

Use for:

* Hero headlines
* Section titles
* Promotional text

Example:

```css
font-family: "Bebas Neue", sans-serif;
```

Hero headline:

```text
72px desktop
48px tablet
40px mobile
```

Example:

> BIG BURGER.
> BIGGER FLAVOR.

---

## Body Font

Use:

**Inter**

```css
font-family: "Inter", sans-serif;
```

Body text:

```text
16–18px
line-height: 1.6
```

Navigation:

```text
14–16px
font-weight: 600
```

---

# Shape Language

Use moderately rounded shapes.

```css
--radius-sm: 8px;
--radius-md: 12px;
--radius-lg: 20px;
--radius-xl: 28px;
--radius-full: 9999px;
```

Buttons:

```text
12px radius
```

Menu cards:

```text
20–24px radius
```

Promotional badges:

```text
9999px radius
```

Avoid making every element pill-shaped.

# Hero Section

The hero should immediately communicate the product.

Desktop layout:

```text
-----------------------------------------

Headline                 Burger Image

Description              Floating badge

[Order Now]
[See Menu]

-----------------------------------------
```

Example content:

```text
THE BURGER
YOU'VE BEEN
CRAVING.

Juicy beef, melted cheese,
fresh vegetables, and our
signature homemade sauce.

[Order Now] [Explore Menu]
```

Burger image should occupy approximately:

```text
45–55% of hero width
```

Use:

* Large burger photography
* Soft shadow underneath
* Slight rotation
* Floating ingredients
* Minimal decorative illustrations

Optional floating elements:

```text
Tomato
Cheese
Lettuce
Chili
Sesame
```

Do not overcrowd the hero.

# Icon Style

Use outline icons.

Recommended size:

```text
20–24px
```

Stroke:

```text
1.75–2px
```

Keep icons minimal and consistent.

Suitable icon categories:

* Shopping bag
* Arrow right
* Star
* Location
* Clock
* Flame
* Leaf
* Instagram

---

# Imagery

Photography should be:

* High contrast
* Warm
* Bright
* Sharp
* Appetizing

Burger images should emphasize:

* Melted cheese
* Juicy beef
* Crispy texture
* Fresh lettuce
* Sauce

Avoid overly perfect AI-looking food imagery.

Prefer natural imperfections.

---

# Decorative Elements

Allowed:

```text
Hand-drawn arrows
Stars
Small circles
Food ingredient illustrations
Sticker labels
Simple checker patterns
```

Use sparingly.

Do not use:

```text
Heavy gradients
Glass cards
Neon effects
Huge drop shadows
Complex 3D shapes
```

---

# Animation

Animations should be playful but subtle.

Hero burger:

```text
fade + translate upward
```

Menu cards:

```text
hover translateY(-4px)
```

CTA:

```text
small scale feedback
```

Floating ingredients:

```text
slow vertical floating animation
```

Duration:

```text
200–500ms UI transitions
```

Avoid aggressive scroll animations.

# Responsive Design

## Mobile

Hero:

```text
Headline
Description
CTA
Burger image
```

instead of desktop side-by-side layout.

Hero title:

```text
40px
```

Menu:

```text
1 card per row
or
horizontal carousel
```

CTA buttons:

```text
full width
```

Navigation converts into hamburger menu.

---

# Accessibility

Minimum touch target:

```text
44–48px
```

Maintain readable text contrast.

Never communicate:

```text
Spicy
Vegetarian
Discount
Availability
```

using color alone.

Provide text labels or icons as well.

---

# Overall Visual Rule

The visual hierarchy should always be:

```text
Burger
↓
Headline
↓
Price / Promotion
↓
CTA
↓
Supporting content
```

The landing page should make visitors feel hungry before making them think about the interface itself.
